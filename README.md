### 2. Линия КАЛАНДИЯ / КАЛАНДАДЗЕ, ЛУКАВА, КАКУЧИЯ и КУХИЛАВА
> **Ключевое семейное предание рода (со слов деда Михи Каландия через тётю Нону / тётю Альдону):**  
> Исконная фамилия рода — **КАЛАНДАДЗЕ (კალანდაძე)**, родом из **Гурии**. Из-за кровной вражды / конфликта предкам пришлось бежать из Гурии в Мегрелию (Зугдиди, Цаленджиха), где фамилия была адаптирована на мегрельский лад — **Каландия (კალანდია)**.

* **Биту Каландадзе / Каландия** (დიდი ბაბუის მამა для Альдоны → прапрапрадедушка для Теймураза)
  * **Бачу Битуевич Каландия** (დიდი ბაბუა для Альдоны → прапрадедушка для Теймураза)
    * Брак с: **Кесо Кухилава (კესო ქუხილავა)** — мать Михаила и его братьев!
    * Дети Бачу и Кесо Кухилава:
      * **Михаил (Миха) Бачуевич Каландия** (უშუალოდ ბაბუა для Альдоны → дедушка Лейлы, прадед Теймураза)
        * Брак с: **Евдокия Павловна Лукава** (Прабабушка)
        * Дети Михи и Евдокии:
          * **Евгения (Женя) Михайловна Каландия** (Бабушка Теймураза) + **Орест Георгиевич Папава**
          * **Шалва Михайлович Каландия** (Отец Альдоны)
            * Дети Шалвы:
              * **Альдона Шалвовна Каландия** (жива, проживает в Тбилиси)
              * **Медея Шалвовна Каландия** (родная сестра Альдоны)
                * Сыновья Медеи: **Ираклий** и **Леван**
              * **Гия (Георгий) Шалвович Каландия** (брат Альдоны и Медеи, умер много лет назад)
                * Сын: **Георгий Каландия** (назван в честь отца)
          * **Надежда (Надя) Михайловна Каландия** (Сестра бабушки Жени, род. ок. 1910–1911 в год знаменитого большого снегопада в Сухуми, сконч. ок. 1997–1998)
            * Приёмная дочь: **Нанули Гигенеишвили** (скончалась ок. 2014 г.)
          * **Нина Михайловна Каландия** (Сестра бабушки Жени, род. 02.10.1923)
            * Дочь: **Нона** (жива)
              * Сын: **Ника**
          * **Отар Боджгуа (Каландия)** (Брат бабушки Жени, род. 1926) + жена **Этери Церцвадзе** (официально Этери; мать Майко, Додо и Вахтанга)
            * Дети Отара и Этери:

### 3. Линия ЛУКАВА и КАКАЧИЯ (из села Обуджи / ობუჯი)
> Семья Лукава происходит из древнего мегрельского села **Обуджи (ობუჯი)** (ныне Цаленджихский муниципалитет).  
> Переселились в Абхазию (Нижняя Абжаква под Сухуми) **в 1880-х годах XIX века**!

* **Павел Лукава (პავლე ლუკავა)** (Прапрадед, родом из Обуджи, ок. 1880-х переселился в Абхазию)
  * Брак с: **Саломе Какачия (სალომე კაკაჩია)** (Прапрабабушка)
  * Дочери Павла Лукава и Саломе Какачия (4 сестры):
    1. **Евдокия Павловна Лукава** (Прабабушка Теймураза, бабушка Альдоны, муж — Михаил Каландия)
    2. **Параскева Павловна Лукава (პარასკევა)**
    3. **Марине Павловна Лукава (მარინე)**
    4. **Ольга Павловна Лукава (ოლღა)**

## 📂 Структура репозитория
* `README.md` — общая сводка, родословная схема и статус поиска.
* `family_tree.ged` — генеалогическое древо в международном формате GEDCOM (импортируется в Gramps, MyHeritage, FamilySearch).
